Reference picture for a storyboard library. Draw EXACTLY what DATA.description describes, in the film's style.

DATA.kind says what the subject is. Follow its rule:
- person: one person, full body, standing, front three-quarter view, neutral expression, arms relaxed so clothes are
  fully visible.
- animal / creature: one animal or creature with its natural anatomy (the right number of legs, wings, tails), full
  body, three-quarter view. No clothes, hands or human features unless the description names them.
- object (a thing that acts as a character, e.g. a paper boat or a letter): only the object, centred, clearly lit,
  exactly as described (shape, material, colours, markings). No face, eyes or limbs unless the description says so.
- group (a crowd, flock, swarm or herd): a small representative cluster of 3 to 7 members of the group, close
  together, showing their shared look. If the members are not people, there are NO people in the picture.
- effect (lights, glow, magic, weather): only the effect itself, e.g. scattered glowing points of light floating in
  the air. No bodies, no faces, no people, no animals.

Never draw a human unless DATA.description describes a human.

Plain light-grey seamless background. Even, soft studio lighting. Nothing else in the frame: no props unless the
description lists them, no text, no labels, no captions, no watermark, no border. Every detail in the description
(colours, size, markings, clothes) must match precisely: this picture becomes the fixed model used in every shot.

Anatomy and props (strict):
- Every character has exactly the body its description implies: the right number of legs, arms, wings, hands and
  fingers. Never add arms or hands the subject does not have.
- Hands have five fingers. Nothing floats, duplicates or merges.
